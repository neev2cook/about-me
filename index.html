🚀 Project System Architecture

This advanced engineering project implements a 4-wheel-drive autonomous follower robot powered by an intelligent Finite State Machine (FSM) control loop. The architecture fuses computer vision tracking with robust industrial sensory safeguards [1]:

  • HuskyLens Smart Vision: Uses hardware UART (Serial1 at 9600 baud) to track object centers and target bounding-box widths [1].
  • Cytron MD10-POT Drivers: Coordinates independent parallel PWM and direction commands across the left and right drive wheel pairs [1].
  • Pepperl+Fuchs ML100 Sensors: Four directional optical sensors configured as active LOW to manage full obstacle avoidance routines [1].
  • Four-Channel Relay Interface: Governs automated safety protocols, including a 24V drive bus contactor, reverse alarms, and hazard horns [1].

⚙️ Core Target Tracking Logic

The robot calculates steering paths and target boundaries using structured pixel thresholds (320 × 240 frame format) [1]:

  • Left Tracking Range: Triggered when the image target horizontal position (x) drops below 110 [1].
  • Right Tracking Range: Triggered when the image target horizontal position (x) exceeds 210 [1].
  • Proximity Stop: Activated instantly if the target bounding-box width grows greater than 140 (target too close) [1].
  • Pursuit Threshold: Active when target bounding-box width drops below 70 (target too far) [1].
